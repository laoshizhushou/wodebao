# 《二次函数的图像与性质》教学设计

## 基本信息
- 学科：数学
- 年级：初中九年级
- 教材版本：北师大版
- 课题：二次函数的图像与性质
- 课时：3课时（本节为第1课时——y=ax²的图像与性质）
- 地区：青海
- 特别说明：结合中考考点

## 教学目标

### 知识与技能
- 会用描点法画出 y = ax² 的图像
- 掌握 y = ax² 的图像特征和性质（开口方向、对称轴、顶点、增减性）
- 理解系数 a 的正负和大小对图像的影响
- 能根据图像性质解决简单的中考基础题

### 过程与方法
- 经历"列表→描点→连线"的画图过程，培养数形结合思想
- 通过观察、比较、归纳，发展数学思维能力
- 通过中考真题训练，掌握二次函数图像的解题方法

### 情感态度与价值观
- 感受数学图像的对称美
- 体会"特殊到一般"的数学思想方法
- 增强对中考数学的信心

## 教学重难点

### 教学重点
- y = ax² 的图像画法
- y = ax² 的图像性质（开口方向、对称轴、顶点坐标、最值）

### 教学难点
- 理解 a 的绝对值大小对开口宽窄的影响
- 利用图像性质解决中考综合问题

## 第一课时

### 一、导入新课（5分钟）

**情境导入**：
展示几组图片：篮球抛物的轨迹、喷泉水柱的弧线、拱桥的形状。

师：同学们，这些曲线都有一个共同的名字——抛物线。在数学中，什么样的函数图像是抛物线呢？

生：二次函数！

师：对！今天我们就来系统研究二次函数的图像与性质。这是中考的必考内容，每年至少出现1-2题，我们必须拿下！

板书课题：二次函数的图像与性质（一）

**知识回顾**：
- 二次函数的一般形式：y = ax² + bx + c（a ≠ 0）
- 一次函数 y = kx + b 的图像是一条直线
- 画函数图像的方法：列表→描点→连线

### 二、探究新知——y = x² 的图像（12分钟）

**活动1：用描点法画 y = x² 的图像**

学生动手在坐标纸上画图，教师巡视指导。

**第一步：列表**

| x | -3 | -2 | -1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|---|
| y = x² | 9 | 4 | 1 | 0 | 1 | 4 | 9 |

**第二步：描点**（学生在坐标纸上标出各点）

**第三步：用平滑曲线连线**

教师强调：
- 连线要用平滑曲线，不能折线连接
- 注意曲线的趋势——向两端无限延伸

**活动2：观察 y = x² 的图像特征**

引导学生观察并总结：
1. 图像形状：抛物线
2. 开口方向：向上
3. 对称轴：y 轴（即 x = 0）
4. 顶点坐标：(0, 0)
5. 顶点是最___点？（最低点）
6. y 的最小值为___？（0）

### 三、对比探究——y = -x² 的图像（8分钟）

**活动3：在同一坐标系中画 y = -x² 的图像**

| x | -3 | -2 | -1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|---|
| y = x² | 9 | 4 | 1 | 0 | 1 | 4 | 9 |
| y = -x² | -9 | -4 | -1 | 0 | -1 | -4 | -9 |

**观察对比**：

| 性质 | y = x² | y = -x² |
|------|--------|---------|
| 开口方向 | 向上 | 向下 |
| 对称轴 | y 轴（x = 0） | y 轴（x = 0） |
| 顶点坐标 | (0, 0) | (0, 0) |
| 顶点意义 | 最低点 | 最高点 |
| 最值 | y最小值 = 0 | y最大值 = 0 |
| 增减性（x < 0） | y 随 x 增大而减小 | y 随 x 增大而增大 |
| 增减性（x > 0） | y 随 x 增大而增大 | y 随 x 增大而减小 |

**关键发现**：y = x² 和 y = -x² 的图像关于 x 轴对称！

### 四、深入探究——系数 a 的影响（10分钟）

**活动4：用 GeoGebra 动态演示 y = ax² 的图像**

教师操作课件，改变 a 的值，学生观察：

| a 的值 | 开口方向 | 开口宽窄 |
|--------|---------|---------|
| a = 2 | 向上 | 较窄 |
| a = 1 | 向上 | 标准 |
| a = 1/2 | 向上 | 较宽 |
| a = -1 | 向下 | 标准 |
| a = -2 | 向下 | 较窄 |

**归纳性质**：
1. **a 的正负决定开口方向**：
   - a > 0 → 开口向上
   - a < 0 → 开口向下

2. **|a| 的大小决定开口宽窄**：
   - |a| 越大 → 开口越小（图像越窄，越"瘦"）
   - |a| 越小 → 开口越大（图像越宽，越"胖"）

> 记忆口诀：a 正开口朝上笑，a 负开口朝下哭；|a| 越大嘴巴越小，|a| 越小嘴巴越大。

### 五、中考链接（10分钟）

**【中考真题1】（基础）**（2024·青海）
关于二次函数 y = 3x² 的图像，下列说法正确的是（  ）
A. 开口向下  B. 对称轴是 x = 3  C. 顶点坐标是 (0, 0)  D. 当 x > 0 时，y 随 x 增大而减小

【答案】C
【解析】a = 3 > 0，开口向上，A 错；对称轴是 y 轴（x = 0），B 错；顶点为 (0, 0)，C 对；a > 0 时，x > 0 部分 y 随 x 增大而增大，D 错。

**【中考真题2】（基础）**（改编）
已知点 A(-2, y₁)、B(1, y₂) 在函数 y = x² 的图像上，则 y₁ 与 y₂ 的大小关系是（  ）
A. y₁ > y₂  B. y₁ < y₂  C. y₁ = y₂  D. 无法确定

【答案】A
【解析】y₁ = (-2)² = 4，y₂ = 1² = 1，所以 y₁ > y₂。
另解（图像法）：y = x² 开口向上，对称轴 x = 0，A 到对称轴距离为 2，B 到对称轴距离为 1，距离越远 y 值越大，所以 y₁ > y₂。

**【中考真题3】（中等）**
已知二次函数 y = ax² 的图像经过点 (2, -12)。
(1) 求 a 的值；
(2) 写出该函数图像的开口方向、对称轴和顶点坐标；
(3) 当 -1 ≤ x ≤ 3 时，求 y 的取值范围。

【答案】
(1) 将 (2, -12) 代入 y = ax²：-12 = 4a，a = -3
(2) a = -3 < 0，开口向下；对称轴为 y 轴（x = 0）；顶点坐标 (0, 0)
(3) y = -3x²，开口向下，顶点 (0, 0) 为最高点
   - x = 0 时，y最大值 = 0
   - x = 3 时，y = -3×9 = -27（距对称轴最远，y最小）
   - 所以 y 的取值范围为 -27 ≤ y ≤ 0

### 六、课堂总结（3分钟）

**知识梳理**：

| y = ax² 的性质 | 内容 |
|---------------|------|
| 图像形状 | 抛物线 |
| 对称轴 | y 轴（直线 x = 0） |
| 顶点坐标 | (0, 0) |
| 开口方向 | a > 0 向上；a < 0 向下 |
| 开口大小 | |a| 越大开口越小 |
| 增减性 | a > 0：左降右升；a < 0：左升右降 |
| 最值 | a > 0 有最小值 0；a < 0 有最大值 0 |

## 第二课时（概要）

**内容**：y = ax² + k 和 y = a(x-h)² 的图像与性质
- 上下平移规律：y = ax² → y = ax² + k（上加下减）
- 左右平移规律：y = ax² → y = a(x-h)²（右加左减）
- 中考重点：平移后新图像的顶点坐标和对称轴

## 第三课时（概要）

**内容**：y = a(x-h)² + k 的图像与性质
- 顶点式：顶点为 (h, k)，对称轴为 x = h
- 一般式 y = ax² + bx + c 化为顶点式（配方法）
- 中考综合：二次函数与几何图形结合的综合题
