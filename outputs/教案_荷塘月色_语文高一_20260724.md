# 《荷塘月色》教学设计

## 基本信息
- 学科：语文
- 年级：高中一年级
- 教材版本：人教版
- 课时：2课时
- 课题：《荷塘月色》（朱自清）

## 教学目标

### 知识与技能
- 掌握文中的重点字词（如：蓊蓊郁郁、袅娜、羞涩、渺茫等）
- 理清文章的行文线索（情感线索+游踪线索）
- 学习并赏析文中比喻、通感、叠词等修辞手法
- 理解情景交融的写作手法

### 过程与方法
- 通过朗读品味散文的语言美
- 通过小组合作探究文章的结构与主旨
- 通过分析修辞手法，提升文学鉴赏能力

### 情感态度与价值观
- 体会作者"淡淡的哀愁与淡淡的喜悦"交织的复杂情感
- 感受作者对自然之美的热爱，培养审美情趣
- 理解知识分子在特定时代背景下的精神世界

## 教学重难点

### 教学重点
- **比喻、通感、叠词等修辞手法的赏析**（本课核心，需重点突出）
- 第4-6自然段（荷塘月色核心段落）的精读与品味
- 情景交融写作手法的理解与运用

### 教学难点
- 通感修辞的理解与鉴赏（如"微风过处，送来缕缕清香，仿佛远处高楼上渺茫的歌声似的"）
- 理解作者"颇不宁静"的深层含义及时代背景
- 把握"淡淡的哀愁与淡淡的喜悦"的情感基调

## 教学准备
- 教师准备：多媒体课件（含荷塘月色实景图/视频、配乐朗读音频）
- 学生准备：预习课文，标注生字词；查阅朱自清生平及写作背景资料

## 教学过程

### 第一课时

#### 一、导入新课（5分钟）

**情境导入**：
展示一幅荷塘月色的图片，配一段轻柔的古筝曲。

提问："看到这幅画面，你会想到哪些词语或诗句？"

学生自由发言后，教师引入：
"现代著名散文家朱自清先生，在一个夏夜独自漫步在清华园的荷塘边，用他细腻的笔触为我们描绘了一幅如诗如画的荷塘月色。今天，我们就一起走进这篇经典散文——《荷塘月色》。"

**背景介绍**：
- 写作时间：1927年7月，正值大革命失败后的白色恐怖时期
- 朱自清当时的处境：作为一位有良知的知识分子，内心苦闷彷徨
- 开篇名句："这几天心里颇不宁静"——奠定了全文的情感基调

#### 二、初读课文，整体感知（10分钟）

1. **配乐范读**：教师播放名家朗诵音频，学生闭目聆听，感受文章的语言节奏与情感氛围

2. **字词检测**（板书重点字词）：
   - 蓊蓊(wěng)郁郁  袅娜(niǎo nuó)  羞涩(sè)  渺茫(miǎo)
   - 踱(duó)步  煤屑(xiè)  倩(qiàn)影  敛(liǎn)裾(jū)
   - 棹(zhào)  纤(xiān)腰  乘(chéng)凉  脉脉(mò mò)

3. **理清结构**：请学生快速默读全文，用一句话概括每个自然段的大意，然后归纳文章结构：

   | 段落 | 内容概括 |
   |------|---------|
   | 第1段 | 点明"颇不宁静"，决定去荷塘 |
   | 第2-3段 | 去荷塘的小路，感受月下独处 |
   | 第4段 | 描写荷叶、荷花（荷塘） |
   | 第5段 | 描写月光（月色） |
   | 第6段 | 荷塘四周的景物 |
   | 第7-8段 | 联想江南采莲，回到现实 |

   **明确两条线索**：
   - 游踪线索：家中→小路→荷塘→家中
   - 情感线索：不宁静→寻求宁静→短暂超脱→回归现实

#### 三、精读第4段：赏析荷塘之美（20分钟）

**重点修辞手法赏析**（核心环节）：

1. **比喻的妙用**

   教师引导学生找出第4段中所有的比喻句：

   | 本体 | 喻体 | 效果 |
   |------|------|------|
   | 叶子 | 亭亭的舞女的裙 | 写出荷叶舒展、轻盈的姿态 |
   | 荷花（开着的） | 一粒粒的明珠、碧天里的星星 | 写出荷花在月光下晶莹闪亮的质感 |
   | 荷花（未开的） | 羞涩地打着朵儿 | 赋予荷花少女般的娇羞之美 |

   **追问**：为什么用"亭亭的舞女的裙"来比喻荷叶？如果用"绿色的大伞"行不行？

   引导学生体会：舞女的裙有旋转时展开的动感和飘逸之美，而"大伞"太死板，没有生命力。好的比喻不仅形似，更要神似。

2. **通感的精妙**（★本课重点）

   **重点赏析句**："微风过处，送来缕缕清香，仿佛远处高楼上渺茫的歌声似的。"

   **教师引导**：
   - 清香是______（嗅觉），歌声是______（听觉）
   - 作者为什么要把嗅觉转化为听觉？
   - 清香的特点是什么？→ 若有若无、断断续续
   - 渺茫的歌声的特点是什么？→ 隐隐约约、时断时续
   - 两者在"似有似无"这一点上产生了通感

   **通感定义**：将一种感官的感受用另一种感官的词语来描绘的修辞手法。

   **拓展训练**：让学生尝试仿写通感句——
   - "那笛声里，仿佛有故乡泥土的______（气息）"
   - "她的笑容像______（一种声音）"

3. **叠词的韵律美**

   找出第4段中的叠词：曲曲折折、田田、亭亭、层层、一粒粒、密密、脉脉

   提问：如果把"曲曲折折的荷塘"改成"弯曲的荷塘"，表达效果有何不同？

   明确：叠词增加了音韵美和节奏感，读起来朗朗上口，同时强化了事物的特征。

4. **动静结合**

   - 静态描写："叶子出水很高""层层的叶子中间，零星地点缀着些白花"
   - 动态描写："微风过处，送来缕缕清香""叶子底下是脉脉的流水"
   - 动静结合使画面更加生动、富有层次感

#### 四、课堂小结（3分钟）

本节课重点赏析了第4段荷塘的景物描写，学习了比喻、通感、叠词三种修辞手法的运用，体会了朱自清散文语言的精炼之美。下节课我们将继续赏析月光之美和荷塘四周的景物描写。

#### 五、作业布置（2分钟）
1. 背诵第4-5段（重点段落）
2. 仿照第4段的写法，选择一处你熟悉的景物，运用比喻和通感写一段200字左右的描写
3. 预习第5-6段，思考：作者是如何描写"月光"这一无形之物的？

---

### 第二课时

#### 一、复习导入（5分钟）
1. 请两位学生背诵第4段中自己喜欢的比喻句
2. 快速回顾通感的概念

#### 二、精读第5段：赏析月色之美（15分钟）

1. **动词的精妙**

   找出第5段中的关键动词：
   - "月光如流水一般，静静地**泻**在这一片叶子和花上"
   - "薄薄的青雾**浮**起在荷塘里"
   - "月光是隔了树照过来的……**画**在荷叶上"

   **追问**：
   - "泻"字能不能换成"照"？→ "泻"有流动感，与"如流水一般"呼应，"照"太直白
   - "浮"字能不能换成"升"？→ "浮"写出雾的轻柔缥缈，"升"方向感太强，缺少朦胧感
   - "画"字妙在哪里？→ 赋予月光以画家的主观能动性，暗示这是大自然的艺术创作

2. **虚实结合**

   - 实写：月光、荷叶、荷花
   - 虚写："叶子和花仿佛在牛乳中洗过一样""又像笼着轻纱的梦"
   - 虚实结合营造出朦胧、梦幻的意境

3. **光影和谐**

   "塘中的月色并不均匀；但光与影有着和谐的旋律，如梵婀玲上奏着的名曲。"
   - 又是通感！视觉（光影）→ 听觉（名曲）
   - 光与影的明暗变化，如同小提琴曲的起伏节奏

#### 三、精读第6段：荷塘四周（10分钟）

1. **以动衬静**
   - "这时候最热闹的，要数树上的蝉声与水里的蛙声"
   - 蝉声、蛙声越热闹，越反衬出环境的幽静
   - 这是一种什么手法？→ 以动衬静（以声写静）

2. **情感的微妙转变**
   - "但热闹是它们的，我什么也没有"
   - 从"独处之乐"转向"孤独之感"
   - 呼应开头"颇不宁静"——自然之美带来短暂超脱，但终究无法排遣内心的苦闷

#### 四、探究主旨（10分钟）

**核心讨论**：
1. 文章开头说"这几天心里颇不宁静"，结尾又说"这令我到底惦着江南了"——作者的情感经历了怎样的变化？

   情感变化轨迹：
   ```
   不宁静（苦闷）→ 寻求宁静（出门）→ 短暂超脱（赏景）→ 回归现实（忆江南）→ 更深的惆怅
   ```

2. "我且受用这无边的荷香月色好了"中的"且"字怎么理解？
   → "且"意为"暂且"，暗示这种超脱是暂时的，终将回到现实的苦闷中

3. 结合时代背景，谈谈你对"颇不宁静"的理解
   → 既有个人情感因素，更有时代知识分子的忧国忧民之情

#### 五、拓展延伸（3分钟）

比较阅读：朱自清《背影》中的父爱描写 vs 本文的自然景物描写
思考：朱自清散文的共同特点是什么？（语言朴素而富有感情、细节传神、情景交融）

#### 六、作业布置（2分钟）
1. 完成课上布置的仿写作段（200字，运用比喻和通感描写一处景物）
2. 写一篇300字的短文，赏析《荷塘月色》中你最喜欢的一段，要求结合具体语句分析修辞手法的表达效果
3. 课外阅读朱自清《绿》《桨声灯影里的秦淮河》，体会其散文风格

## 板书设计

```
              荷塘月色
                朱自清

  线索：不宁静 → 求宁静 → 暂超脱 → 归现实

  ┌─────────────────────────────────────┐
  │  第4段：荷塘                         │
  │  · 荷叶：亭亭的舞女的裙（比喻）      │
  │  · 荷花：明珠、星星（比喻）          │
  │  · 清香→歌声（通感·嗅觉→听觉）      │
  │  · 叠词：曲曲折折、田田、亭亭…      │
  ├─────────────────────────────────────┤
  │  第5段：月色                         │
  │  · 泻（流动）浮（缥缈）画（主动）    │
  │  · 光影→名曲（通感·视觉→听觉）      │
  ├─────────────────────────────────────┤
  │  第6段：四周（以动衬静）              │
  │  "热闹是它们的，我什么也没有"        │
  └─────────────────────────────────────┘

  核心手法：比喻 + 通感 + 叠词 + 情景交融
```

## 教学反思
（课后填写）
- 学生对通感的理解程度如何？是否需要补充更多例句？
- 朗读环节的参与度是否足够？配乐是否恰当？
- 时间分配是否合理？第4段的赏析是否充分？
