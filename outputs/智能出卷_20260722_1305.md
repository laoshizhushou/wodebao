# 参考答案与解析

## 一、选择题

**1.【答案】C**

【解析】一元二次方程需满足：只含一个未知数、未知数最高次数为2、整式方程。A含两个未知数；B化简后为2x = -1，是一次方程；D不是整式方程。只有C满足所有条件。

---

**2.【答案】B**

【解析】方程 2x² - 3x + 1 = 0 中，二次项系数为2，一次项系数为-3（注意符号），常数项为1。

---

**3.【答案】C**

【解析】x² = 4，直接开平方得 x = ±√4 = ±2。

---

**4.【答案】A**

【解析】x² + 6x - 7 = 0 → x² + 6x = 7 → x² + 6x + 9 = 7 + 9 → (x + 3)² = 16。配方时一次项系数6的一半为3，3² = 9，两边同时加9。

---

**5.【答案】C**

【解析】判别式 Δ = b² - 4ac = (-4)² - 4(1)(5) = 16 - 20 = -4 < 0，所以方程没有实数根。

---

**6.【答案】B**

【解析】将 x = 1 代入方程：1² + b(1) - 2 = 0 → 1 + b - 2 = 0 → b = 1。

---

**7.【答案】A**

【解析】由韦达定理，x₁ + x₂ = -(-5)/1 = 5。也可以直接求解：x² - 5x + 6 = 0 → (x-2)(x-3) = 0 → x₁ = 2, x₂ = 3，所以 x₁ + x₂ = 5。

---

**8.【答案】A**

【解析】每次降价百分率为x，第一次降价后为 200(1-x)，第二次降价后为 200(1-x)(1-x) = 200(1-x)²。根据题意：200(1-x)² = 162。

---

**9.【答案】B**

【解析】要使方程为一元二次方程，二次项系数 (m-1) 不能为0，即 m - 1 ≠ 0，所以 m ≠ 1。

---

**10.【答案】A**

【解析】修建十字形小路后，剩余部分可以拼成一个长为(10-x)m、宽为(8-x)m的长方形。所以 (10-x)(8-x) = 54。

---

## 二、填空题

**11.【答案】3x² - 6x = 0；常数项为 0**

【解析】将 3x² = 6x 移项得 3x² - 6x = 0，常数项为0。

---

**12.【答案】x₁ = 5，x₂ = -1**

【解析】(x-2)² = 9，开平方得 x-2 = ±3，所以 x = 2+3 = 5 或 x = 2-3 = -1。

---

**13.【答案】x₁ = 0，x₂ = 3**

【解析】x² - 3x = 0 → x(x - 3) = 0 → x = 0 或 x - 3 = 0 → x₁ = 0，x₂ = 3。

---

**14.【答案】m = ±4**

【解析】有两个相等的实数根，则判别式 Δ = 0。Δ = m² - 4(1)(4) = m² - 16 = 0，解得 m² = 16，m = ±4。

---

**15.【答案】x₁ · x₂ = 1/2**

【解析】由韦达定理，x₁ · x₂ = c/a = 1/2。

---

**16.【答案】x² = x + 12（或 x² - x - 12 = 0）；边长为 4**

【解析】正方形面积为 x²，边长为 x，面积比边长多12：x² = x + 12。解方程：x² - x - 12 = 0 → (x-4)(x+3) = 0 → x = 4 或 x = -3（舍去负值），边长为4。

---

**17.【答案】x₁ = 3，x₂ = -1**

【解析】x² - 2x - 3 = 0 → (x-3)(x+1) = 0 → x = 3 或 x = -1。

---

**18.【答案】k ≤ 9/4**

【解析】有实数根，则 Δ ≥ 0。Δ = 3² - 4(1)(k) = 9 - 4k ≥ 0，解得 k ≤ 9/4。

---

**19.【答案】100(1+x)² = 121；x = 10%**

【解析】从2024年到2026年经过2年，年增长率为x，则 100(1+x)² = 121。(1+x)² = 1.21，1+x = 1.1（取正值），x = 0.1 = 10%。

---

**20.【答案】m = 0；另一个根为 1**

【解析】将 x = 0 代入方程：0² - (m+1)(0) + m = 0 → m = 0。当 m = 0 时，方程为 x² - x = 0 → x(x-1) = 0 → x₁ = 0，x₂ = 1。另一个根为1。
