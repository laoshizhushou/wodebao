3. 若关于 x 的方程 (m-1)x² + 3x - 1 = 0 是一元二次方程，则 m 的取值范围是（  ）
   A. m ≠ 0  B. m ≠ 1  C. m = 1  D. m 为任意实数

4. 方程 x² = 4 的解为（  ）

6. 一元二次方程 2x² - 3x - 2 = 0 的根为（  ）
   A. x = 2 或 x = -1/2  B. x = -2 或 x = 1/2  C. x = 2 或 x = 1/2  D. x = -2 或 x = -1/2

7. 已知一元二次方程 x² + bx + c = 0 的两根分别为 x₁ = 1, x₂ = -3，则 b、c 的值分别为（  ）

9. 某商品原价 200 元，经过两次降价后售价为 162 元，若每次降价的百分率相同，设每次降价的百分率为 x，则所列方程为（  ）
   A. 200(1-x)² = 162  B. 200(1+x)² = 162  C. 200(1-2x) = 162  D. 200(1-x²) = 162

10. 一块矩形菜地长 20m，宽 15m，在菜地中间修两条等宽的小路（一横一竖），使剩余种植面积为 234m²，则小路宽为（  ）

22.（8分）阅读材料：
解方程 (x² - 1)² - 5(x² - 1) + 4 = 0 时，我们可以将 x² - 1 看作一个整体，设 x² - 1 = y，那么原方程变为 y² - 5y + 4 = 0，解得 y₁ = 1, y₂ = 4。
当 y = 1 时，x² - 1 = 1，x² = 2，x = ±√2；
当 y = 4 时，x² - 1 = 4，x² = 5，x = ±√5。
所以原方程的解为 x₁ = √2, x₂ = -√2, x₃ = √5, x₄ = -√5。

请利用以上方法解方程：x⁴ - x² - 6 = 0。

# 参考答案与解析

## 一、选择题

1. 【答案】B
   【解析】A 含两个未知数，不是一元方程；C 是一元一次方程；D 中 1/x 不是整式。只有 B：x² - 2x = 0 满足"只含一个未知数、未知数最高次数为2、整式方程"三个条件。

2. 【答案】A
   【解析】x² - 5x + 6 = 0，分解因式：(x - 2)(x - 3) = 0，所以 x₁ = 2, x₂ = 3。

3. 【答案】B
   【解析】一元二次方程要求二次项系数不为 0，即 m - 1 ≠ 0，所以 m ≠ 1。

4. 【答案】C
   【解析】x² = 4，直接开平方得 x = ±2。

5. 【答案】A
   【解析】x² + 6x + 5 = 0，x² + 6x = -5，x² + 6x + 9 = -5 + 9，(x + 3)² = 4。

6. 【答案】A
   【解析】2x² - 3x - 2 = 0，用因式分解法：(2x + 1)(x - 2) = 0，所以 x = -1/2 或 x = 2。

7. 【答案】A
   【解析】由韦达定理：x₁ + x₂ = 1 + (-3) = -b，所以 b = 2；x₁ · x₂ = 1 × (-3) = c，所以 c = -3。

8. 【答案】A
   【解析】有两个相等的实数根，则判别式 Δ = 0。Δ = (-4)² - 4k = 16 - 4k = 0，所以 k = 4。

9. 【答案】A
   【解析】第一次降价后价格为 200(1-x)，第二次降价后为 200(1-x)(1-x) = 200(1-x)²，所以 200(1-x)² = 162。

10. 【答案】C
    【解析】设小路宽为 x m。种植面积 = 20 × 15 - 20x - 15x + x² = 300 - 35x + x² = 234，即 x² - 35x + 66 = 0，(x - 2)(x - 33) = 0。因 x < 15，所以 x = 3m。

## 二、填空题

11. 【答案】x₁ = 0, x₂ = 7
    【解析】x² - 7x = 0，x(x - 7) = 0，所以 x = 0 或 x = 7。

12. 【答案】3x² - 5x + 2 = 0，二次项系数为 3
    【解析】移项得 3x² - 5x + 2 = 0。

13. 【答案】m = 2，另一个根为 x₂ = 2
    【解析】将 x = 1 代入：1 - 3 + m = 0，m = 2。方程为 x² - 3x + 2 = 0，(x - 1)(x - 2) = 0，另一个根为 x = 2。

14. 【答案】x₁ = 5, x₂ = -1
    【解析】(x - 2)² = 9，x - 2 = ±3，x = 2 ± 3，所以 x₁ = 5, x₂ = -1。

15. 【答案】m = 0 或 m = 2
    【解析】完全平方式要求判别式 Δ = 0。Δ = 4(m-1)² - 4m² = 4(m² - 2m + 1 - m²) = 4(1 - 2m) = 0，所以 m = 1/2。

    等等，重新计算：x² + 2(m-1)x + m² = 0 是完全平方式，即该式 = (x + a)² 的形式。
    判别式 Δ = [2(m-1)]² - 4·1·m² = 4(m-1)² - 4m² = 4(m² - 2m + 1 - m²) = 4(1 - 2m) = 0
    所以 m = 1/2。

    【修正答案】m = 1/2

16. 【答案】100(1 + x)² = 121
    【解析】第一年 100 吨，第二年 100(1+x) 吨，第三年 100(1+x)² = 121。

17. 【答案】x₁ + x₂ = 5，x₁ · x₂ = 6
    【解析】由韦达定理直接得出。

## 三、解答题

18.（1）【解答】
    x² - 4x + 1 = 0
    x² - 4x = -1
    x² - 4x + 4 = -1 + 4
    (x - 2)² = 3
    x - 2 = ±√3
    x = 2 ± √3
    所以 x₁ = 2 + √3, x₂ = 2 - √3

    （2）【解答】
    2x² + 5x - 3 = 0
    a = 2, b = 5, c = -3
    Δ = b² - 4ac = 25 - 4(2)(-3) = 25 + 24 = 49
    x = (-b ± √Δ) / (2a) = (-5 ± 7) / 4
    x₁ = (-5 + 7) / 4 = 2/4 = 1/2
    x₂ = (-5 - 7) / 4 = -12/4 = -3

19.（1）【解答】
    Δ = (2k+1)² - 4(k²+k) = 4k² + 4k + 1 - 4k² - 4k = 1
    Δ = 1 > 0，对任意实数 k，方程都有两个不相等的实数根。
    所以 k 的取值范围为 k 为任意实数。

    （2）【解答】
    将 x = 2 代入方程：
    4 - (2k+1)×2 + k² + k = 0
    4 - 4k - 2 + k² + k = 0
    k² - 3k + 2 = 0
    (k - 1)(k - 2) = 0
    k = 1 或 k = 2

20.（1）【解答】
    垂直于墙的边长为 x m，则平行于墙的边长为 (24 - 2x) m
    S = x(24 - 2x) = -2x² + 24x（其中 0 < x < 12）

    （2）【解答】
    S = 70 时：
    -2x² + 24x = 70
    2x² - 24x + 70 = 0
    x² - 12x + 35 = 0
    (x - 5)(x - 7) = 0
    x = 5 或 x = 7
    当 x = 5 时，平行于墙的边长 = 24 - 10 = 14m
    当 x = 7 时，平行于墙的边长 = 24 - 14 = 10m
    两种情况均满足条件，所以 x = 5m 或 x = 7m。

21. 【解答】
    设每台冰箱降价 50x 元（x 为非负整数对应降价次数），则：
    每台售价为 (2900 - 50x) 元
    每台利润为 (2900 - 50x - 2500) = (400 - 50x) 元
    每天售出 (8 + 4x) 台
    
    总利润 = (400 - 50x)(8 + 4x) = 5000
    展开：3200 + 1600x - 400x - 200x² = 5000
    -200x² + 1200x + 3200 = 5000
    -200x² + 1200x - 1800 = 0
    x² - 6x + 9 = 0
    (x - 3)² = 0
    x = 3
    
    每台冰箱定价 = 2900 - 50 × 3 = 2750 元
    验证：每台利润 400 - 150 = 250 元，每天售出 8 + 12 = 20 台
    总利润 = 250 × 20 = 5000 元 ✓

22. 【解答】
    设 x² = t（t ≥ 0），则原方程变为：
    t² - t - 6 = 0
    (t - 3)(t + 2) = 0
    t₁ = 3, t₂ = -2
    
    当 t = 3 时：x² = 3，x = ±√3
    当 t = -2 时：x² = -2 < 0，无实数解
    
    所以原方程的解为 x₁ = √3, x₂ = -√3。
