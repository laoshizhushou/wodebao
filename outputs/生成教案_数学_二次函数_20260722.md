## 教学目标

### 知识与技能
- 掌握二次函数 y=ax²、y=ax²+k、y=a(x-h)²、y=a(x-h)²+k 的图像画法与基本性质

- 能根据已知条件确定二次函数的解析式
- 掌握中考常见题型的解题方法

- 通过列表、描点、连线的过程，培养画图与观察能力

- 感受函数图像的对称美与数学的严谨性
- 增强中考备考信心，建立系统的知识框架

## 第一课时（45分钟）：二次函数的图像基本性质

### 一、中考真题导入（5分钟）

**展示青海中考真题**：

> 【2024·青海】已知二次函数 y=ax²+bx+c 的图像如图所示，下列结论正确的是（  ）
> A. a>0  B. c<0  C. b>0  D. b²-4ac>0

"这道题每年的中考几乎都会考，很多同学丢分。学完今天这节课，你们就能秒杀这类题。"

### 二、知识梳理与图像探究（20分钟）

#### 知识点1：y=ax² 的基本图像

**活动1：动手画图**

列表画出 y=x² 的图像：

| x | -3 | -2 | -1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|---|
| y=x² | 9 | 4 | 1 | 0 | 1 | 4 | 9 |

学生用坐标纸描点画图，教师巡视指导。

**归纳性质**：

| 性质 | a>0 | a<0 |
|------|-----|-----|
| 开口方向 | 向上 | 向下 |
| 顶点坐标 | (0, 0) | (0, 0) |
| 对称轴 | x=0（y轴） | x=0（y轴） |
| 最值 | 最小值 y=0 | 最大值 y=0 |
| 增减性 | x<0时递减，x>0时递增 | x<0时递增，x>0时递减 |
| \|a\|的作用 | \|a\|越大，开口越小 | \|a\|越大，开口越小 |

**中考点睛**：
> ⭐ **|a|越大，开口越小**——这是选择题常考的"陷阱"！a的正负决定开口方向，|a|的大小决定开口宽窄。

#### 知识点2：y=ax²+k 的图像与平移

**活动2：对比观察**

利用GeoGebra动态演示，同时展示 y=x²、y=x²+2、y=x²-3 的图像。

**归纳平移规律**：
- k>0 → 图像向上平移 k 个单位
- k<0 → 图像向下平移 |k| 个单位
- **口诀：上加下减**

| 函数 | 顶点 | 对称轴 | 开口方向 |
|------|------|--------|---------|
| y=x² | (0,0) | x=0 | 向上 |
| y=x²+2 | (0,2) | x=0 | 向上 |
| y=x²-3 | (0,-3) | x=0 | 向上 |

#### 知识点3：y=a(x-h)² 的图像与平移

**活动3：类比探究**

展示 y=x²、y=(x-2)²、y=(x+1)² 的图像。

**归纳平移规律**：
- h>0 → 图像向右平移 h 个单位
- h<0 → 图像向左平移 |h| 个单位
- **口诀：左加右减**（注意是对x而言）

#### 知识点4：y=a(x-h)²+k（顶点式）

**核心归纳**：

> **顶点式：y = a(x-h)² + k**
> - 顶点坐标：**(h, k)**
> - 对称轴：**x = h**
> - 当 a>0 时，开口向上，最小值为 k
> - 当 a<0 时，开口向下，最大值为 k

**平移总结（中考必考）**：

```
y = ax²
  ↓ 左加右减（h控制水平平移）
y = a(x-h)²
  ↓ 上加下减（k控制竖直平移）
y = a(x-h)²+k
```

> ⭐ **中考口诀**："左加右减看括号，上加下减看后面"

### 三、中考基础训练（15分钟）

**【中考真题1】（选择题·3分）**

二次函数 y = -2(x-3)²+1 的图像，下列说法错误的是（  ）
A. 开口向下
B. 对称轴为 x=3
C. 顶点坐标为 (3, 1)
D. 当 x>3 时，y 随 x 增大而增大

**解析**：
- a=-2<0 → 开口向下 ✓（A对）
- h=3 → 对称轴 x=3 ✓（B对）
- 顶点 (3, 1) ✓（C对）
- a<0，对称轴右侧(x>h)，y随x增大而**减小** ✗（D错）

**答案：D**

**【中考真题2】（填空题·3分）**

将抛物线 y=3x² 先向左平移2个单位，再向上平移5个单位，所得抛物线的解析式为______。

**解析**：
- y=3x² → 左移2 → y=3(x+2)² → 上移5 → y=3(x+2)²+5

**答案：y = 3(x+2)²+5**

**【中考真题3】（解答题·6分）**

已知二次函数的图像顶点为 (1, -4)，且经过点 (3, 0)，求此二次函数的解析式。

**解题步骤**：
1. 设顶点式：y = a(x-1)²-4
2. 代入 (3, 0)：0 = a(3-1)²-4 = 4a-4
3. 解得 a=1
4. 解析式：y = (x-1)²-4 = x²-2x-3

### 四、课堂小结（3分钟）

| 知识要点 | 关键词 |
|---------|--------|
| 顶点式 | y=a(x-h)²+k，顶点(h,k) |
| 平移口诀 | 左加右减，上加下减 |
| a的作用 | 正负定方向，大小定宽窄 |

2. 画出 y=-(x+1)²+3 的图像，标出顶点和对称轴
3. 【中考备战】完成发放学案第1-10题

## 第二课时（45分钟）：系数 a、b、c 与图像的关系

### 一、复习导入（3分钟）

快速回顾上节课的顶点式与平移规律。

### 二、核心考点突破（25分钟）

#### 考点1：各系数的几何意义（中考必考★）

**活动4：从图像读信息**

在多媒体上展示一个二次函数图像（开口向下，与y轴交于正半轴，对称轴在y轴右侧），引导学生逐一分析：

| 系数 | 判断依据 | 本图结论 |
|------|---------|---------|
| **a** | 开口方向：a>0向上，a<0向下 | a<0（开口向下） |
| **b** | 对称轴 x=-b/(2a) 的位置 | 需结合a判断（见下） |
| **c** | 与y轴交点(0,c)的位置 | c>0（交于y轴正半轴） |
| **b²-4ac** | 与x轴交点个数 | >0有2个交点 |

**⭐ b的符号判断法（学生最容易搞混）**：

```
对称轴 x = -b/(2a)

对称轴在y轴左侧（-b/(2a)<0）:
  → 若 a>0，则 b>0  （同正）
  → 若 a<0，则 b<0  （同负）
  → 记忆：左同
  
对称轴在y轴右侧（-b/(2a)>0）:
  → 若 a>0，则 b<0  （异号）
  → 若 a<0，则 b>0  （异号）
  → 记忆：右异
```

> ⭐ **秒杀口诀："左同右异"**
> - 对称轴在y轴**左**侧 → a和b**同**号
> - 对称轴在y轴**右**侧 → a和b**异**号

#### 考点2：特殊位置的值

| 代入x的值 | 得到的表达式 | 对应图像上 |
|-----------|------------|-----------|
| x=1 | a+b+c | 图像上点(1, a+b+c)的高低 |
| x=-1 | a-b+c | 图像上点(-1, a-b+c)的高低 |
| x=2 | 4a+2b+c | 图像上点(2, 4a+2b+c)的高低 |
| x=-2 | 4a-2b+c | 图像上点(-2, 4a-2b+c)的高低 |

**常考判断**：
- 若图像上 x=1 的点在x轴上方 → a+b+c > 0
- 若图像上 x=-1 的点在x轴下方 → a-b+c < 0

#### 考点3：经典中考真题实战

**【中考真题4】（选择题·3分）**

二次函数 y=ax²+bx+c 的图像如图所示，下列结论：
① abc>0  ② b<a+c  ③ 4a+2b+c>0  ④ a+b>m(am+b)（m≠1）

其中正确的结论有（  ）
A. 1个  B. 2个  C. 3个  D. 4个

**（教师带领逐步分析）**

已知条件（从图像读出）：
- 开口向上 → a>0
- 对称轴 x=1，在y轴右侧 → 左同右异 → b<0（与a异号）
- 与y轴交于负半轴 → c<0
- 与x轴有两个交点 → b²-4ac>0

逐个判断：
- ① abc>0：a>0, b<0, c<0 → abc = (+)×(-)×(-) = (+)>0 ✓
- ② b<a+c：即 a-b+c>0，代入x=-1时图像上的点在...需看图判断
- ③ 4a+2b+c>0：即x=2时的函数值，看图判断
- ④ a+b>m(am+b)：即x=1时的函数值是最小值（因为a>0，顶点在x=1）

**答案：C（①③④正确）**

> ⭐ **这类题是青海中考选择压轴题，每年必考3分，必须拿下！**

### 三、专项训练（12分钟）

**【中考真题5】（青海模拟·选择·3分）**

如图所示，二次函数 y=ax²+bx+c 的图像经过以下信息：
- 开口向下
- 对称轴为 x=-1
- 与y轴交于正半轴

则下列判断正确的个数是（  ）
① a<0 ② b>0 ③ c>0 ④ 2a-b=0 ⑤ a-b+c>0

A. 2个 B. 3个 C. 4个 D. 5个

**解析**：
- ① a<0 ✓（开口向下）
- ② 对称轴 x=-b/(2a)=-1，即 b=2a，因a<0，所以b<0 ✗
- ③ c>0 ✓（与y轴交于正半轴）
- ④ 2a-b=0 → b=2a ✓（由对称轴推出）
- ⑤ a-b+c>0 → 代入x=-1：a(-1)²+b(-1)+c=a-b+c，看图x=-1是对称轴处，即顶点，开口向下顶点在最高点，由图知顶点在x轴上方 ✓

**答案：C（①③④⑤正确，共4个）**

### 四、课堂小结（3分钟）

**中考秒杀技巧汇总**：

```
1. a 看开口：上正下负
2. b 看对称轴："左同右异"
3. c 看y轴截距：上正下负零过原
4. b²-4ac 看x轴交点个数
5. a+b+c 看x=1时图像的高低
6. a-b+c 看x=-1时图像的高低
```

## 第三课时（45分钟）：中考综合应用与压轴题型

### 一、中考应用题突破（20分钟）

#### 题型1：最大利润/最大面积问题

**【中考真题6】（解答题·8分）**

青海某牧民要用长40m的围栏靠河围成一个矩形的牧区（河作为一边，不需要围栏），设垂直于河的边长为xm。

（1）写出矩形面积S关于x的函数关系式；
（2）当x取何值时，矩形面积最大？最大面积是多少？

**解题过程**：

（1）平行于河的边长 = 40-2x
- S = x(40-2x) = -2x²+40x
- 自变量范围：0<x<20

（2）S = -2x²+40x = -2(x²-20x) = -2(x-10)²+200

- a=-2<0，开口向下，有最大值
- 当 x=10 时，S最大=200 m²

**答**：当垂直于河的边长为10m时，面积最大为200m²。

> ⭐ **中考建模三步法**：
> 1. 设变量，找等量关系
> 2. 列出二次函数（注意自变量范围！）
> 3. 用顶点式求最值

#### 题型2：抛物线型实际问题

**【中考真题7】（解答题·8分）**

一座拱桥的桥洞是抛物线形。以桥洞的最高点为原点建立坐标系，桥洞经过点(4,-5)（单位：m）。

（1）求抛物线的解析式；
（2）当水位上涨1m时，水面宽度是多少？

**解题过程**：

（1）设 y=ax²，代入(4,-5)：
- -5 = 16a → a = -5/16
- y = -5/16 x²

（2）水位上涨1m → y=-4（从原点往下4m）
- -4 = -5/16 x²
- x² = 64/5
- x = ±8/√5 ≈ ±3.58
- 水面宽度 = 2×8/√5 = 16√5/5 ≈ 7.16m

### 二、中考压轴题思路点拨（15分钟）

**【中考压轴题框架】（第28题·12分）**

> 如图，在平面直角坐标系中，抛物线 y=ax²+bx+c 经过A(-1,0)、B(3,0)、C(0,-3)三点。
> （1）求抛物线的解析式；（4分）
> （2）在抛物线的对称轴上是否存在点P，使得PA+PC的值最小？若存在，求出P点坐标；（4分）
> （3）在抛物线上是否存在点M，使得△MAB的面积等于△CAB的面积？若存在，求出M点坐标。（4分）

**（教师示范第(1)(2)问的解题思路）**

**第(1)问**：
方法一：设一般式 y=ax²+bx+c，代入三点坐标
- A(-1,0)：a-b+c=0
- B(3,0)：9a+3b+c=0
- C(0,-3)：c=-3

解方程组得 a=1, b=-2, c=-3
∴ y=x²-2x-3

方法二（更快）：A、B是与x轴交点，设交点式
- y=a(x+1)(x-3)
- 代入C(0,-3)：-3=a(1)(-3)=-3a → a=1
- y=(x+1)(x-3)=x²-2x-3

> ⭐ **有x轴交点坐标时，优先用交点式 y=a(x-x₁)(x-x₂)！**

**第(2)问**：
- 对称轴 x=(-1+3)/2=1
- PA+PC最小 → 利用对称性：A和B关于对称轴对称
- 所以PA=PB，即求PB+PC最小值
- 当P在BC连线上时PB+PC最小
- 求直线BC：B(3,0), C(0,-3)，斜率k=(-3-0)/(0-3)=1
- 直线BC：y=x-3
- 当x=1时，y=-2
- ∴ P(1,-2)
