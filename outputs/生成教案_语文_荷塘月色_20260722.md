# 《荷塘月色》教学设计

## 基本信息
- 学科：语文
- 年级：高中一年级
- 教材版本：人教版
- 课时：2课时（90分钟）
- 地区：青海

## 教学目标

### 知识与技能
- 掌握本文中的比喻、拟人、通感、叠词等修辞手法，能准确识别并分析其表达效果
- 理解散文"形散神聚"的特点，把握文章的情感线索
- 积累文中优美的语言片段，提升散文鉴赏能力

### 过程与方法
- 通过朗读品味，感受文章的语言之美
- 通过修辞手法的分类赏析，学习散文鉴赏的基本方法
- 通过小组合作探究，培养审美鉴赏与批判性思维能力

### 情感态度与价值观
- 体会作者在特定时代背景下对美好事物的追求与内心的淡淡哀愁
- 感受自然之美，培养对生活中美的感知能力
- 理解知识分子在困境中的精神寄托与人格追求

## 教学重难点

### 教学重点
- **比喻、拟人、通感**三种修辞手法的识别与赏析
- 叠词在文中的运用及其音韵效果
- 第四、五、六自然段（重点写景段落）的修辞分析

### 教学难点
- 通感手法的理解与运用（如"微风过处，送来缕缕清香，仿佛远处高楼上渺茫的歌声似的"）
- 理解修辞手法背后作者情感的投射（景语皆情语）
- 体会"淡淡的喜悦"与"淡淡的哀愁"交织的复杂情感

## 教学准备
- 教师准备：多媒体课件（含荷塘月色实景图片、配乐朗诵音频）、修辞手法归纳卡片
- 学生准备：预习课文，标注自己不理解的语句；复习初中所学的比喻、拟人等修辞知识

## 第一课时（45分钟）

### 一、导入新课（5分钟）

**情境导入**：

展示月下荷塘的摄影作品，配以轻柔的古筝音乐。

"同学们，在一个月光如水的夜晚，独自漫步在一片幽静的荷塘边，你会是什么样的心情？"

学生自由发言后，教师引入：

"1927年的夏天，在清华大学园内，有一位学者也独自漫步在荷塘边。他叫朱自清。那时的中国，正处于风雨飘摇之中。带着心里的苦闷与彷徨，他写下了这篇传世名作——《荷塘月色》。今天，我们就一起走进这片荷塘，重点去品味朱自清是用怎样精妙的修辞手法，为我们描绘出这幅传世佳作的。"

**板书课题**：荷塘月色 —— 朱自清

### 二、整体感知（8分钟）

**活动1：快速梳理文章结构**

学生快速浏览全文，教师引导梳理：

| 段落 | 内容 | 情感变化 |
|------|------|----------|
| 第1段 | 起因：心里颇不宁静 | 不宁静 |
| 第2-3段 | 去荷塘的路上 | 淡淡的喜悦 |
| 第4-6段 | 荷塘月色（重点写景） | 喜悦、陶醉 |
| 第7-8段 | 联想江南采莲 | 思乡、惆怅 |
| 第9段 | 回家 | 回到现实 |

**提问**：文章的情感基调是什么？
**明确**："这几天心里颇不宁静"→ 出门寻静 → 在荷塘获得短暂的宁静与喜悦 → 最终回到现实。全文笼罩着一层**"淡淡的喜悦"与"淡淡的哀愁"**。

### 三、重点修辞手法赏析（25分钟）

#### （一）比喻的妙用（8分钟）

**活动2：找出文中的比喻句并分析**

引导学生找出文中经典的比喻句：

> ① "叶子出水很高，像亭亭的舞女的裙。"

**分析**：
- 本体：荷叶 → 喻体：舞女的裙
- 相似点：舒展、轻盈、优美
- 表达效果：将静态的荷叶写出了动态之美，赋予荷叶以生命力，令人联想到舞女旋转时裙摆飘展的优美姿态

> ② "层层的叶子中间，零星地点缀着些白花……正如一粒粒的明珠，又如碧天里的星星，又如刚出浴的美人。"

**分析**：
- 连用三个比喻（博喻），分别从不同角度描绘荷花
  - "明珠"—— 写荷花在月光下的**光泽**（晶莹剔透）
  - "星星"—— 写荷花的**分布**（疏密有致、闪烁灵动）
  - "刚出浴的美人"—— 写荷花的**气质**（清新脱俗、纤尘不染）
- 表达效果：多角度、多层次地展现荷花之美，层层递进，令人目不暇接

**教师点拨**：这就是"博喻"——用一个本体、多个喻体来描绘事物，是朱自清散文的重要修辞特色。

> ③ "月光如流水一般，静静地泻在这一片叶子和花上。"

**分析**：
- 本体：月光 → 喻体：流水
- "泻"字的妙处：化静为动，将月光的倾洒写得如流水般流畅自然
- 表达效果：月光有了动态的美感，既写出了月光的明亮充沛，又体现了月华的柔和流畅

#### （二）拟人的巧用（7分钟）

**活动3：找出文中的拟人句并品味**

> ① "层层的叶子中间，零星地点缀着些白花，有袅娜地开着的，有羞涩地打着朵儿的。"

**分析**：
- "袅娜"—— 本形容女子体态柔美，此处写荷花盛开姿态
- "羞涩"—— 本形容人的害羞情态，此处写含苞待放的花骨朵
- 表达效果：赋予荷花以少女般的娇羞与柔美，既写出了荷花的不同姿态（盛开与含苞），又增添了文章的柔美意境

> ② "叶子本是肩并肩密密地挨着。"

**分析**：
- "肩并肩"—— 拟人化描写荷叶的紧密排列
- 表达效果：赋予荷叶以人的亲密感，既写出了荷叶的茂密，又营造出一种热闹而温馨的氛围

> ③ "月光也像是另有番用意似的……"

**分析**：
- 赋予月光以人的心思
- 表达效果：仿佛月光也在有意为之，增添了一份神秘与浪漫

**教师归纳**：朱自清的拟人手法有一个特点——**总是将景物比作"人"，尤其偏向女性化的柔美形象**，这使得整篇文章呈现出一种婉约、柔美的风格。

#### （三）通感的精妙（10分钟）

**活动4：重点突破通感修辞**

> 经典例句："微风过处，送来缕缕清香，仿佛远处高楼上渺茫的歌声似的。"

**教师讲解**：
- **什么是通感？** 通感又叫"移觉"，是将一种感官的感受用另一种感官来表达的修辞手法。简单说就是"感觉的转移"。
- **分析**：
  - "缕缕清香"—— **嗅觉**感受（荷花的香气）
  - "远处高楼上渺茫的歌声"—— **听觉**感受
  - 将嗅觉转化为听觉！
- **为什么这样写？**
  - 清香是若有若无、时断时续的
  - 远处高楼上的歌声也是隐隐约约、似有似无的
  - 两者的**共同特征**是"若有若无、缥缈不定"
  - 用听觉来表达嗅觉，更能传达那种**朦胧、缥缈、不可捉摸**的美感

> 另一个通感例句："塘中的月色并不均匀；但光与影有着和谐的旋律，如梵婀玲上奏着的名曲。"

**分析**：
- "光与影"—— **视觉**感受
- "和谐的旋律""名曲"—— **听觉**感受
- 将视觉转化为听觉，用音乐的和谐来表现光影的协调
- 表达效果：让静态的景物有了音乐的律动感，增强了文章的意境之美

**小组讨论**（3分钟）：通感和比喻有什么区别？
**明确**：
- 比喻：本体和喻体必须是不同类事物，但要有相似点（A像B）
- 通感：必须是**不同感官之间**的转换（视觉→听觉、嗅觉→听觉等）
- 通感实质上是一种特殊的比喻，但它侧重于"感官的迁移"

### 四、课堂小结（5分钟）

**师生共同归纳**：

本节课我们重点分析了《荷塘月色》中三种核心修辞手法：

| 修辞手法 | 典型例句 | 表达效果 |
|---------|---------|---------|
| 比喻（博喻） | 荷花如明珠、星星、美人 | 多角度展现景物之美 |
| 拟人 | 袅娜地开着、羞涩地打着朵儿 | 赋予景物以人的情感与姿态 |
| 通感 | 清香仿佛歌声、光影如名曲 | 打通感官，营造朦胧意境 |

**思考题**：朱自清为什么要在这些景物上使用如此多的修辞手法？这和他当时的心情有什么关系？（下节课讨论）

### 五、作业布置
1. 熟读第4-6自然段，背诵经典段落
2. 从文中再找出3处比喻句和2处拟人句，写出具体的赏析（100字/处）
3. 预习：思考"叠词"在文中的运用效果

## 第二课时（45分钟）

### 一、复习导入（3分钟）

回顾上节课分析的比喻、拟人、通感三种修辞手法。请2-3位同学分享作业中找到的修辞句及赏析。

### 二、叠词修辞的音韵之美（10分钟）

**活动5：品味叠词的音乐美**

引导学生找出文中的叠词：

| 叠词 | 所在句 | 效果 |
|------|--------|------|
| 曲曲折折 | 曲曲折折的荷塘 | 写出荷塘的蜿蜒绵延 |
| 田田 | 田田的叶子 | 写出荷叶的茂密相连 |
| 亭亭 | 亭亭的舞女的裙 | 写出荷叶的高挑挺拔 |
| 层层 | 层层的叶子 | 写出荷叶的错落有致 |
| 密密 | 密密地挨着 | 写出荷叶的紧密排列 |
| 脉脉 | 脉脉的流水 | 写出流水的含情默默 |
| 静静 | 静静地泻 | 写出月光的安宁柔和 |
| 淡淡 | 淡淡的月色 | 写出月光的朦胧轻柔 |
| 缕缕 | 缕缕清香 | 写出清香的连绵不断 |
| 点点 | 点点滴滴 | 写出细雨的零落轻柔 |

**归纳**：
- **音韵效果**：叠词使语言具有回环往复的音乐美感，读起来朗朗上口
- **表意效果**：加强语意的程度，使描写更加细腻、传神
- **情感效果**：营造出一种舒缓、柔美的节奏，与文章"淡淡"的情感基调相吻合

**拓展**：叠词是朱自清散文的标志性语言特色。《春》中也有大量叠词："偷偷地""嫩嫩的""绿绿的""轻悄悄"等。

### 三、修辞与情感的关联（15分钟）

**活动6：深入探究——景语皆情语**

**核心问题**：朱自清为什么要把荷塘月色写得如此之美？使用了如此多的修辞手法，仅仅是为了写景吗？

**小组讨论**（5分钟）后，教师引导明确：

1. **以美景寄深情**：
   - 修辞手法越精美 → 说明作者在这片荷塘中获得的慰藉越深
   - 现实中的朱自清"心里颇不宁静"（1927年大革命失败后的白色恐怖）
   - 荷塘成为他的精神避难所，修辞之美反映了他对美好世界的向往

2. **以"热闹"衬"孤寂"**：
   - 文中用大量修辞把荷塘写得生机盎然、热闹美丽
   - 但这一切都是"我"独自一人在月下观赏的
   - "热闹是它们的，我什么也没有" —— **以乐景写哀情**

3. **修辞中的情感密码**：
   - "亭亭的舞女的裙""刚出浴的美人"—— 对美好事物的向往
   - "羞涩地打着朵儿"—— 含蓄内敛的审美追求
   - "脉脉的流水"—— 内心无法言说的愁绪
   - 所有修辞都笼罩着一层**朦胧、缥缈**的色彩—— 正如作者心中那份说不清道不明的哀愁

**板书总结**：
```
修辞之美 → 景物之美 → 精神寄托 → 情感抒发
（形式）     （内容）    （深层）     （核心）
```

### 四、拓展迁移（10分钟）

**活动7：学以致用——仿写练习**

请学生运用今天学到的修辞手法，写一段100字左右的景物描写。

**要求**：
1. 至少使用2种修辞手法（比喻、拟人、通感、叠词任选）
2. 描写一处你熟悉的自然景物
3. 要融入自己的情感

**示例**（教师示范）：
> 校园后面的小花园，曲曲折折的石子路蜿蜒其间。几株丁香静静地站在暮春的风里，紫红色的花簇一团团地挤在枝头，像极了放学时蜂拥而出的学生们——热闹、蓬勃、充满着生命的张力。空气里弥漫着甜丝丝的花香，那香气仿佛是一首温柔的老歌，在鼻尖轻轻哼唱着，让人想起童年院子里那棵老槐树下，外婆摇着蒲扇讲故事的黄昏。

**学生写作**（5分钟），请2-3位同学朗读，师生共同点评修辞运用。

### 五、课堂总结（5分钟）

**全文总结**：

《荷塘月色》是朱自清散文的代表作，其修辞艺术堪称中国现代散文的典范：

1. **比喻**——多角度（博喻）、化静为动（月光如流水）
2. **拟人**——女性化的柔美（袅娜、羞涩）
3. **通感**——打通感官（清香如歌、光影如曲）
4. **叠词**——音韵之美（田田、亭亭、脉脉……）

这些修辞手法不是简单的文字游戏，而是作者情感的外化。正如王国维所说："一切景语皆情语。"朱自清用精妙的修辞，在荷塘月色中建构了一个属于自己的精神世界——**在最美的文字里，藏着最深的忧愁**。

### 六、作业布置
1. 背诵第4-6自然段
2. 写一篇300字左右的赏析短文：《我眼中的荷塘月色——修辞之美》
3. 课外阅读：朱自清《春》《背影》，比较其修辞风格的异同

## 板书设计

```
                    荷塘月色
                     朱自清

    ┌── 比喻：明珠·星星·美人（博喻）── 多角度之美
    │                                  月光如流水 ── 化静为动
修辞├── 拟人：袅娜·羞涩·肩并肩 ──── 赋予人的情态
    │
    ├── 通感：清香→歌声 ──────────── 感官迁移
    │        光影→名曲 ──────────── 化视觉为听觉
    │
    └── 叠词：曲曲折折·田田·亭亭 ─── 音韵回环之美
             脉脉·静静·淡淡 ─────── 舒缓柔美

    核心：一切景语皆情语 → 以乐景写哀情
```

## 教学反思
（课后填写）
- 学生对通感手法的理解程度如何？是否需要更多例证？
- 仿写练习的时间是否充足？学生能否准确运用所学修辞？
- 情感分析环节是否需要结合更多历史背景资料？
