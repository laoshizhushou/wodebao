### 人教版高中一年级生物第五章“光合作用”知识点梳理

#### 1. 核心概念与定义

- **光合作用**：绿色植物、某些细菌和藻类利用光能将二氧化碳和水转化为有机物（主要是葡萄糖）并释放氧气的过程。
- **光反应**：光合作用中，在光照条件下发生的化学反应，主要在叶绿体的类囊体膜上进行，产生ATP和NADPH。
- **暗反应**（又称Calvin循环）：光合作用中不直接依赖光的化学反应，主要在叶绿体基质中进行，通过固定CO2生成有机物。
- **叶绿体**：植物细胞中进行光合作用的细胞器，含有叶绿素等色素。
- **叶绿素**：叶绿体中主要的光合色素，能够吸收光能并将其转化为化学能。
- **光合色素**：参与光合作用的色素，包括叶绿素a、叶绿素b、类胡萝卜素等。
- **光合磷酸化**：在光反应中，光能被转化为化学能，使ADP和无机磷酸合成ATP的过程。
- **水的光解**：光反应中水分子在光的作用下分解，产生氧气、电子和H+。
- **光合单位**：由多个叶绿素分子、其他色素分子以及相关蛋白质组成的功能单位，是光合作用的基本单位。
- **光合链**：一系列电子传递体组成的系统，负责将光能转化为化学能。
- **CO2的固定**：暗反应中，CO2被固定为有机物的过程，通常以五碳糖（RuBP）为接受体。
- **光补偿点**：光合作用速率与呼吸作用速率相等时的光照强度。
- **光饱和点**：光合作用速率不再随光照强度增加而增加时的光照强度。

#### 2. 光合作用的过程与反应方程式

- **总反应方程式**：6CO2 + 6H2O + 光能（叶绿素）→ C6H12O6 + 6O2
- **光反应**：
  - **水的光解**：2H2O + 光能（叶绿素）→ 4e- + 4H+ + O2
  - **光合磷酸化**：ADP + Pi + 光能（叶绿素）→ ATP
  - **NADP+的还原**：NADP+ + 2e- + 2H+ → NADPH
- **暗反应（Calvin循环）**：
  - **CO2的固定**：CO2 + C5（RuBP）→ 2C3（3-磷酸甘油酸）
  - **C3的还原**：3-磷酸甘油酸 + ATP + NADPH → 甘油醛-3-磷酸（G3P）
  - **C5的再生**：G3P + ATP + NADPH → C5（RuBP）

#### 3. 影响光合作用的环境因素

- **光照强度**：在一定范围内，光合作用速率随光照强度的增加而增加，达到饱和点后不再增加。
- **温度**：光合作用速率随温度的升高而增加，但超过最适温度后会下降。
- **CO2浓度**：在一定范围内，光合作用速率随CO2浓度的增加而增加，达到饱和点后不再增加。
- **水分**：水分不足会影响光合作用，因为水分是光合作用的原料之一，且水分不足会导致气孔关闭，减少CO2的吸收。
- **矿质元素**：如N、P、K等矿质元素的供应情况也会影响光合作用，这些元素是合成光合色素和参与光合作用酶的重要成分。

#### 4. 考试常考的重点与易错点

- **重点**：
  - 光合作用的总反应方程式及其意义。
  - 光反应和暗反应的主要场所、过程和产物。
  - 影响光合作用的环境因素及其作用机制。
  - 叶绿体的结构与功能。
  - 光合色素的种类及其吸收光谱。
  - 光合作用的实际应用，如提高作物产量的方法等。
- **易错点**：
  - **光饱和点与光补偿点的概念混淆**：光饱和点是指光合作用速率不再随光照强度增加而增加时的光照强度，而光补偿点是指光合作用速率与呼吸作用速率相等时的光照强度。
  - **光合作用的原料和产物**：光合作用的原料是CO2和水，产物是有机物（如葡萄糖）和氧气，但不少学生易将水误认为是产物。
  - **光反应和暗反应的关系**：光反应和暗反应是相互独立但又紧密联系的两个过程，光反应提供的ATP和NADPH是暗反应进行的必要条件，而暗反应产生的NADP+和ADP又为光反应提供了原料。
  - **光合色素的作用**：光合色素不仅包括叶绿素a和叶绿素b，还包括类胡萝卜素等其他色素，它们共同参与光能的吸收和传递。
