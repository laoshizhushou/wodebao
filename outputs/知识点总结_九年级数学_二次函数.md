# 初中九年级数学 · 第三章 二次函数（人教版）重点归纳

## 一、二次函数的概念

**定义**：一般地，形如 y = ax² + bx + c（a、b、c 是常数，**a ≠ 0**）的函数叫做 x 的二次函数。

- **自变量**：x
- **自变量的取值范围**：全体实数
- **关键点**：a ≠ 0 是二次函数的必要条件（若 a = 0 则退化为一次函数或常函数）

### 三种基本形式

| 形式 | 表达式 | 特点 |
|------|--------|------|
| 一般式 | y = ax² + bx + c | 直接读出 a、b、c 的值 |
| 顶点式 | y = a(x - h)² + k | 直接读出顶点坐标 (h, k) |
| 交点式 | y = a(x - x₁)(x - x₂) | 直接读出与 x 轴的两个交点 |

> ⚠️ 只有当抛物线与 x 轴有两个交点时，才能用交点式。

## 二、二次函数的图像与性质

### 1. y = ax² 的基本图像

- 图像是一条**抛物线**
- **对称轴**：x = 0（即 y 轴）
- **顶点**：(0, 0)

### 2. a 的作用

| a 的值 | 图像特征 |
|--------|---------|
| a > 0 | 开口**向上**，顶点为最低点 |
| a < 0 | 开口**向下**，顶点为最高点 |
| \|a\| 越大 | 开口越**窄**（图像越"瘦"）|
| \|a\| 越小 | 开口越**宽**（图像越"胖"）|

### 3. y = a(x - h)² + k 的图像平移

**口诀："左加右减，上加下减"**

| 平移方式 | 变化 |
|---------|------|
| 向左平移 m 个单位 | h 变为 (h + m)，即 x → x + m |
| 向右平移 m 个单位 | h 变为 (h - m)，即 x → x - m |
| 向上平移 n 个单位 | k 变为 (k + n) |
| 向下平移 n 个单位 | k 变为 (k - n) |

### 4. 关键量与系数的关系

对于 y = ax² + bx + c：

- **对称轴**：x = -b/(2a)
- **顶点坐标**：(-b/(2a), (4ac - b²)/(4a))
- **与 y 轴交点**：(0, c)
- **与 x 轴交点个数**：由判别式 Δ = b² - 4ac 决定
  - Δ > 0 → 两个交点
  - Δ = 0 → 一个交点（相切）
  - Δ < 0 → 无交点

## 三、二次函数的增减性

| 条件 | 增减性 |
|------|--------|
| a > 0，x < -b/(2a) | y 随 x 增大而**减小** ↓ |
| a > 0，x > -b/(2a) | y 随 x 增大而**增大** ↑ |
| a < 0，x < -b/(2a) | y 随 x 增大而**增大** ↑ |
| a < 0，x > -b/(2a) | y 随 x 增大而**减小** ↓ |

**记忆技巧**：a > 0 时"先减后增"（U 形）；a < 0 时"先增后减"（倒 U 形）

---

## 四、二次函数与一元二次方程的关系

二次函数 y = ax² + bx + c 中，令 y = 0，即得一元二次方程 ax² + bx + c = 0。

- 方程的**根** = 函数图像与 x 轴交点的**横坐标**
- 判别式 Δ = b² - 4ac 同时决定：
  - 方程的根的个数
  - 图像与 x 轴的交点个数

### 韦达定理（根与系数的关系）

若 x₁、x₂ 是方程 ax² + bx + c = 0 的两个根，则：
- x₁ + x₂ = -b/a
- x₁ · x₂ = c/a

## 五、二次函数的实际应用

### 常见问题类型

1. **最大利润/最大面积问题** → 利用顶点求最大值（a < 0 时）
2. **抛物线运动问题** → 建立坐标系，利用顶点式和交点式
3. **方案设计问题** → 建立函数模型，结合自变量取值范围求解

### 解题步骤

1. 设自变量，建立二次函数关系式
2. 确定自变量的取值范围（注意实际意义限制）
3. 利用顶点坐标公式求最值
4. 检验结果是否符合实际

---

## 六、常考题型与易错点

### 🔥 高频考点

1. 根据条件求二次函数解析式（待定系数法）
2. 利用图像判断 a、b、c 的正负
3. 利用对称轴和顶点求最值
4. 二次函数与几何图形结合（面积最值）

### ⚠️ 易错点

- 忘记检验 **a ≠ 0**（如：y = (m-1)x² + x 是二次函数，则 m ≠ 1）
- 平移方向搞混（"左加右减"针对的是 x 本身的变化）
- 实际应用题忘记写**自变量取值范围**
- 混淆"最大值"和"最小值"的条件
