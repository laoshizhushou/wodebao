# 第三章 二次函数 重点归纳

## 一、二次函数的概念

### 1.1 定义
一般地，若两个变量 x、y 之间的关系可以表示成 **y = ax² + bx + c**（a、b、c 是常数，a ≠ 0）的形式，则称 y 是 x 的二次函数。

### 1.2 三种基本形式

| 形式 | 表达式 | 特点与用途 |
|------|--------|-----------|
| **一般式** | y = ax² + bx + c (a≠0) | 最常用，可直接读出 a、b、c 的值 |
| **顶点式** | y = a(x - h)² + k (a≠0) | 直接读出顶点坐标 (h, k) 和对称轴 x = h |
| **交点式** | y = a(x - x₁)(x - x₂) | 直接读出与 x 轴的两个交点 (x₁, 0) 和 (x₂, 0) |

### 1.3 重点辨析
- **a ≠ 0** 是二次函数的前提条件，若 a = 0 则退化为一次函数
- 一般式中 b、c 可以为0，如 y = 2x²、y = x² - 3 都是二次函数
- 三种形式之间可以互相转化（配方法是一般式→顶点式的关键方法）

## 二、二次函数的图象与性质

### 2.1 y = ax² 的基本性质

| 性质 | a > 0 | a < 0 |
|------|-------|-------|
| 开口方向 | 向上 | 向下 |
| 顶点 | (0, 0) | (0, 0) |
| 对称轴 | x = 0（即 y 轴） | x = 0（即 y 轴） |
| 最值 | 最小值 y = 0 | 最大值 y = 0 |
| 增减性 | x < 0 时 y 随 x 增大而减小；x > 0 时 y 随 x 增大而增大 | x < 0 时 y 随 x 增大而增大；x > 0 时 y 随 x 增大而减小 |

### 2.2 |a| 的大小与开口的关系
- **|a| 越大，开口越小**（图象越"瘦"）
- **|a| 越小，开口越大**（图象越"胖"）

### 2.3 y = a(x - h)² + k 的图象特征

| 要素 | 由谁决定 |
|------|---------|
| 开口方向 | a 的正负 |
| 开口大小 | \|a\| 的大小 |
| 对称轴 | x = h |
| 顶点坐标 | (h, k) |
| 最值 | a>0 时最小值为 k；a<0 时最大值为 k |

### 2.4 图象的平移规律（重点★）

**口诀：左加右减（针对 x），上加下减（针对 y）**

从 y = ax² 到 y = a(x - h)² + k：
- h > 0：向右平移 h 个单位
- h < 0：向左平移 |h| 个单位
- k > 0：向上平移 k 个单位
- k < 0：向下平移 |k| 个单位

**平移顺序**：先左右平移，再上下平移（顺序不影响最终结果）

## 三、关键参数的确定

### 3.1 对称轴与顶点

由一般式 y = ax² + bx + c：
- **对称轴**：x = -b/(2a)
- **顶点坐标**：(-b/(2a), (4ac - b²)/(4a))

### 3.2 各系数的几何意义

| 系数 | 决定什么 | 判断方法 |
|------|---------|---------|
| a | 开口方向与大小 | a>0 向上，a<0 向下 |
| b | 与 a 共同决定对称轴位置 | ab>0 → 对称轴在 y 轴左侧；ab<0 → 右侧 |
| c | 图象与 y 轴的交点 | c>0 → 交于 y 轴正半轴；c<0 → 负半轴；c=0 → 过原点 |

### 3.3 常考判断题

1. **b² - 4ac > 0**：图象与 x 轴有两个交点
2. **b² - 4ac = 0**：图象与 x 轴有一个交点（顶点在 x 轴上）
3. **b² - 4ac < 0**：图象与 x 轴无交点

---

## 四、二次函数与一元二次方程的关系

### 4.1 核心联系
二次函数 y = ax² + bx + c 与 x 轴的交点的横坐标，就是一元二次方程 ax² + bx + c = 0 的两个根。

### 4.2 对应关系

| 二次函数图象 | 一元二次方程 |
|-------------|-------------|
| 与 x 轴有两个交点 | 有两个不相等的实数根（Δ > 0） |
| 与 x 轴有一个交点 | 有两个相等的实数根（Δ = 0） |
| 与 x 轴无交点 | 没有实数根（Δ < 0） |

---

## 五、求二次函数解析式的方法

### 5.1 待定系数法（中考必考★）

**步骤**：
1. 根据已知条件选择合适的形式（一般式/顶点式/交点式）
2. 将已知点的坐标代入
3. 解方程（组）求出待定系数
4. 写出解析式

### 5.2 选择策略

| 已知条件 | 选择形式 | 示例 |
|---------|---------|------|
| 已知三个点的坐标 | 一般式 | 过 (0,1)、(1,3)、(-1,2) |
| 已知顶点和一个点 | 顶点式 | 顶点(2,-1)，过(0,3) |
| 已知与 x 轴两交点和一个点 | 交点式 | 交于(1,0)和(-3,0)，过(0,6) |

## 六、二次函数的应用（中考高频考点）

### 6.1 最大/最小值问题
**题型特征**：涉及面积最大、利润最大、费用最少等实际问题

**解题步骤**：
1. 设自变量，建立二次函数关系式
2. 确定自变量的取值范围（注意实际意义的限制）
3. 利用顶点公式或配方求最值
4. 验证最值是否在自变量取值范围内

### 6.2 典型应用题模型
- **面积问题**：围栏围矩形面积最大
- **利润问题**：定价与销量的关系
- **抛物线问题**：投掷物体的轨迹、拱桥设计

---

## 七、中考易错点总结

1. **忽略 a ≠ 0 的条件**：求参数取值范围时，若题目说"二次函数"，必须确保 a ≠ 0
2. **平移方向搞混**："左加右减"是对 x 而言，y = a(x+2)² 是左移2个单位，不是右移
3. **对称轴公式记错**：x = -b/(2a)，注意负号
4. **忽略实际取值范围**：应用题中求出的最值必须检验是否在定义域内
5. **顶点式展开时出错**：配方法要仔细，建议展开后验证

## 八、必背公式速记卡

```
一般式：      y = ax² + bx + c（a ≠ 0）
顶点式：      y = a(x - h)² + k
对称轴：      x = -b/(2a)
顶点坐标：    (-b/(2a), (4ac-b²)/(4a))
判别式：      Δ = b² - 4ac
平移口诀：    左加右减，上加下减
```
